# Phase 8: 30-day organic growth and monetisation campaign

Start: 27 Nov 2026 (day 1). All work free. No purchased links, no fake accounts, no
automated posting, no paid engagement.

## Day map

| Days | Dates | Focus |
|---|---|---|
| 1-3 | 27-29 Nov | Foundation: site, analytics, Search Console, Bing, keyword matrix, keyword map |
| 4-7 | 30 Nov - 3 Dec | Launch: sitemap submission, indexing requests, first crawl checks |
| 8-14 | 4-10 Dec | Add genuinely distinct pages, long-tail sections, internal linking pass |
| 15-21 | 11-17 Dec | 2-3 guides, sample datasets, community outreach (shown to the user first) |
| 22-30 | 18-26 Dec | CTR work on titles and descriptions, AdSense readiness review, day-30 report |

## What is done (days 1-7)

- Site live on Cloudflare Pages with 32 URLs: 16 tools, 6 category pages, 3 guides, 5
  site pages, home, 404.
- GA4 property and web stream created, consent-gated. Measurement ID `G-H8TNG17E5G`.
- Search Console URL-prefix property verified by HTML file; sitemap submitted.
- Bing Webmaster: site imported from Search Console, sitemap processed, 32 URLs
  discovered, 0 errors.
- Keyword matrix and keyword-to-URL map written from real autocomplete and SERP data.
- Daily KPI tracker created.

## What is not done, and why

- Search Console shows the homepage as "URL is unknown to Google". Sitemap is submitted
  and Google has not read it yet. Request Indexing returned a quota error and must be
  retried; there is no way to force it.
- No impressions, clicks, positions or sessions exist yet, so the KPI tracker starts at
  zero with the date each metric became available.
- Extra pages for days 8-14 are not built yet. They are only worth building where a
  cluster in the keyword map has no owning URL, which is why the map came first.

## Days 8-14 candidates (build only if genuinely distinct)

Each of these would own a cluster the current site does not:

1. CSV to Excel (the reverse of the existing Excel to CSV). Separate intent, separate
   searchers, and currently a gap in our own catalogue.
2. Trim whitespace and fix casing in a CSV. Distinct from duplicate removal and empty
   row removal; "clean" is too broad to own alone.
3. Find and replace inside a CSV column. Distinct from filtering.
4. CSV column reorder / rename headers. Distinct from extraction.
5. A "how to open a CSV that is too big for Excel" guide. Informational, matches a real
   complaint, links to the viewer.

Rejected: pages for "csv to json python", "json formatter", "csv to pdf", "excel
formulas". Wrong intent or not our tool, and each would be a doorway page.

## Community outreach rules

- Every post is shown to the user before it goes out. No exceptions.
- One post per community, written for that community, answering a real question.
- No links in the first reply of a thread unless the link answers the question asked.
- No sockpuppets, no vote manipulation, no paid placement, no link exchanges.

## Measurement honesty

Each KPI row is marked measured or estimated. Search Console and GA4 numbers are
measured once they exist. Anything from a third-party keyword tool, a guess, or a
projection is labelled estimated, and no projected traffic figure is presented as a
result.
