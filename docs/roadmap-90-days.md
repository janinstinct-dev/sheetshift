# 90-day roadmap

From 27 Nov 2026. Free-only throughout.

## Days 1-30 (to 26 Dec): foundation and first index

- Index the 32 URLs; retry Search Console indexing requests as the quota allows.
- Build 3-5 additional pages only where the keyword map shows an unowned cluster.
- Publish 2-3 guides aimed at the informational queries around CSV problems.
- Publish 1-2 sample datasets on the samples pages so tool pages have something to link.
- Outreach: one careful post per relevant community, each shown to the user first.
- KPI review weekly; day-30 report answering the ten campaign questions.

## Days 31-60 (27 Dec - 25 Jan): depth and CTR

- Rewrite titles and descriptions for pages that get impressions but no clicks, using
  the actual queries Search Console reports.
- Add a second pass of long-tail sections to the three strongest tool pages, based on
  queries we appear for but do not answer well.
- Add one comparison page only if a real cluster appears in the data (e.g. "CSV vs
  TSV"), never to fill a calendar slot.
- Check Core Web Vitals in the field once traffic exists; fix what the data shows.
- Review AdSense readiness again with real traffic numbers.

## Days 61-90 (26 Jan - 24 Feb): consolidate

- Prune or merge any page with no impressions after 60 days rather than letting thin
  pages sit in the index.
- Expand the guides that earn links or long dwell time; leave the rest alone.
- Consider one additional language only if there is evidence of demand; that means
  `hreflang`, translated copy and per-language canonicals, which is a real project.
- Decide on monetisation from measured data, not from the plan.

## Standing constraints

- Nothing that costs money.
- No invented metrics anywhere in reporting.
- No claim of indexing, ranking or traffic without a check.
- Every community post approved by the user before it is posted.
- Tools are only marked complete when they pass the test suite.
